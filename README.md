# Интернет-магазин обуви (Учебный проект)

Приложение для автоматизации работы магазина обуви. Проект разработан в рамках обучения по специальности «Информационные системы и программирование».

**Студент:** Иутина Ольга Валентиновна
**Учебное заведение:** Пермский химико-технологический техникум

## Технологии
*   **Язык программирования:** C#
*   **Интерфейс:** WPF (Windows Presentation Foundation)
*   **База данных:** PostgreSQL
*   **Инструменты:** pgAdmin, Git

## Функционал программы
*   Просмотр каталога обуви (с фильтрацией по категориям и размерам)
*   Просмотр подробной информации о товаре
*   Корзина (добавление/удаление товаров)
*   Оформление заказов (в разработке)
*   Роли пользователей (Администратор, Менеджер, Покупатель)

База данных состоит из связанных таблиц:
*   `products` — товары (название, описание, цена, состав)
*   `categories` / `subcategories` — категории (детская, мужская, женская)
*   `orders` / `order_items` — заказы и их состав
*   `users` / `roles` — пользователи системы и их права
*   `stock_items` — остатки товаров на складе по размерам

1.  Установите PostgreSQL и pgAdmin.
2.  Создайте базу данных (например, `shop_db`).
3.  Выполните скрипт `database/бд.sql` в pgAdmin для создания таблиц и заполнения их тестовыми данными.
4.  Откройте решение (Solution) в Visual Studio.
5.  Проверьте строку подключения к базе данных в коде (обычно в файле `App.config` или классе подключения) и укажите свои логин/пароль от PostgreSQL.
6.  Запустите проект (F5).
